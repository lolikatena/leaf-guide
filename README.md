# Листочек — веб-справочник по болезням растений

Лабораторная работа №1: интерфейс приложения и каркас frontend.

## Назначение приложения

Листочек — справочник, который помогает определить болезнь растения по симптомам
поражения листьев и найти инструкцию по лечению. Пользователь выбирает растение,
видит список самых частых болезней, открывает нужную и читает симптомы и порядок
действий. Инструкции хранятся локально, в самом приложении.

Аудитория: садоводы и дачники, которые заметили на листьях пятна, налёт или
изменение цвета и хотят понять, что это и что делать.

## Пользовательские сценарии

1. **Найти болезнь по растению.** Открыть главную → выбрать растение → посмотреть
   список частых болезней.
2. **Сверить симптомы и прочитать инструкцию.** Открыть болезнь → сравнить описание
   симптомов с тем, что видно на листьях → прочитать, как лечить.
3. **Узнать о справочнике.** Открыть страницу «О справочнике».

## Экраны

| Адрес | Экран | Что делает |
|---|---|---|
| `/` | Растения | Список растений карточками |
| `/plants/:plantId` | Болезни растения | Частые болезни выбранного растения |
| `/plants/:plantId/:diseaseId` | Болезнь | Описание, симптомы и инструкция по лечению |
| `/about` | О справочнике | Назначение приложения |

## Технологии

- **React 18 + TypeScript** — основа интерфейса
- **Vite** — сборка и дев-сервер
- **React Router 6** — клиентская маршрутизация
- **Mantine 7** — библиотека UI-компонентов (заголовки, текст, кнопки)

Mantine выбрана из-за встроенной темы: цвета проекта задаются один раз в
`src/theme.ts`, и все компоненты выглядят единообразно.

## Структура проекта

```
src/
  App.tsx          маршруты
  main.tsx         точка входа
  theme.ts         цвета и шрифты для Mantine
  styles.css       свои стили
  components/      Layout, DiseaseCard
  pages/           HomePage, PlantPage, DiseasePage, AboutPage
  data/plants.ts   список растений и болезней
```

## Запуск frontend

Нужен Node.js 18 или новее.

```bash
npm install     # установить зависимости
npm run dev     # запустить, откроется http://localhost:5173
npm run build   # собрать production-версию в папку dist
```

## Упрощения этого этапа

- **Данные — заглушки.** Вместо настоящих болезней в карточках стоят «Болезнь 1»,
  «Описание болезни 1», «Симптомы 1». У всех растений пока одинаковый набор.
  Настоящее содержимое будет добавлено на следующих этапах.
- **Данные хранятся в коде** (`src/data/plants.ts`), а не на сервере. Структура уже
  та, которая понадобится backend: при подключении API поменяется только источник.
- **Нет поиска и фильтров** — на четырёх экранах и шести растениях они пока не нужны.
